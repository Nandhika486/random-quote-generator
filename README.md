# ✨ Random Quote Generator

A simple and interactive **Random Quote Generator** built using **HTML, CSS, and JavaScript**.

This project provides two ways to generate quotes:
- 📚 Quotes from a predefined collection
- 🌐 Quotes fetched dynamically using an API

The project also focuses on providing a clean, attractive, and user-friendly interface.

---

## Features

- Generate random quotes
-  Includes a predefined collection of quotes
-  Fetch quotes using an external API
-  Displays the quote along with the author
-  Clean and modern user interface
-  Responsive design
- Fast and lightweight
-  Two different JavaScript implementations for quote generation

---

## Technologies Used

- **HTML5** – Structure of the application
- **CSS3** – Styling and responsive user interface
- **JavaScript** – Application logic and random quote generation
- **Fetch API** – Fetching quotes from an external API
